## 🚀 QUICK START

```bash
git clone <YOUR-REPOSITORY-URL>
cd <YOUR-REPOSITORY-FOLDER>

npm install
npm start
```

### Environment

Keep secrets and service credentials in environment variables rather than committing them to GitHub.

Example:

```env
MONGODB_URI=your_mongodb_connection_string
```
